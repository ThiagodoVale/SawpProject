# Input data

Only raw scientific inputs belong under this directory.

```text
raw/era5/              Created by scripts/download_era5.py
raw/domain/            Domain SST and topography NetCDF files
raw/rainfall/monitor/  Measured monthly station text files
interim/               Reproducible temporary products
processed/             Reproducible compact scientific products
```

Raw and generated files are excluded from Git. Empty directories are retained only
to make the required layout visible after cloning.
