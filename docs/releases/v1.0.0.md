# SAWP v1.0.0 release record

Release date: 2026-11-07

SAWP v1.0.0 is the first definitive release of the self-contained scientific capsule.
It regenerates all 18 manuscript figures from the frozen raw-input inventory without
executing archived scripts or reading historical derived NPZ files.

## Frozen scientific conventions

- Analysis period: 1959–2023.
- Season: April–July (AMJJ).
- Climatology: 1980–2010.
- Moisture-flux convergence: `-div(Q)`; positive values denote convergence.
- Vertical-section longitude domain: 60°W–10°W (201 grid columns).
- Equivalent potential temperature: exact legacy dew-point/LCL calculation.
- Figure 9 vector normalization: native pressure-longitude grid before interpolation.

## Release validation

The release is accepted only after these commands succeed:

```powershell
uv sync --frozen --extra dev
uv run --frozen python scripts/verify_raw_inputs.py
uv run --frozen python scripts/reproduce_scientific.py --clean --force
uv run --frozen pytest -q
uv run --frozen ruff check src tests scripts
uv run --frozen python scripts/verify_scientific_reproduction.py
uv run --frozen python scripts/verify_storage_efficiency.py
uv build
uv run --frozen python scripts/freeze_release.py --version 1.0.0
uv run --frozen python scripts/verify_capsule.py --outputs
```

The raw data are intentionally excluded from Git. Their authoritative inventory is
`checksums/raw_inputs.sha256`. The wheel, source distribution, accepted figure rasters,
and their SHA-256 values are recorded by `checksums/release_v1.0.0.json` and
`checksums/release_v1.0.0.sha256`.
