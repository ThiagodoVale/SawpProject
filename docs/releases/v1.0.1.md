# SAWP v1.0.1 release record

Release date: 2026-11-08

SAWP v1.0.1 is a patch release that makes the GitHub Actions validation portable
across hosted runners. Scientific calculations and the 18 accepted publication
figures are unchanged from v1.0.0.

## Changes

- Request Python `3.12` instead of the unavailable exact patch `3.12.14`.
- Validate lint, all tests, and the 18 frozen reference checksums in GitHub Actions.
- Keep the full raw-to-figure reproduction as a local or data-enabled workflow,
  because the raw NetCDF and rain-gauge inputs are intentionally not stored in Git.
- Adopt a policy in which every accepted small change increments the patch version.

## Validation

- `uv sync --frozen --extra dev`: passed.
- Ruff: passed.
- Pytest: 38 passed.
- Frozen reference figures: 18/18 byte-identical.
- Scientific provenance: 18/18 figures.
- Publication identity: 18/18 exact.

## Release artifacts

Build and freeze the release with:

```powershell
uv build
uv run --frozen python scripts/freeze_release.py --version 1.0.1 --date 2026-11-08
```

The wheel, source distribution, sizes, and SHA-256 values are recorded in
`checksums/release_v1.0.1.json` and `checksums/release_v1.0.1.sha256`.
